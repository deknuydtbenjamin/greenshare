# GreenShare 🌱  

GreenShare est un site communautaire dédié aux passionnés de plantes. Il permet aux utilisateurs de partager leurs plantes, d’échanger des conseils, et de se connecter autour de leur amour pour la nature.  

## Objectifs  
- Rassembler une communauté autour des plantes.  
- Offrir un espace pour partager des informations et des astuces.  

## Technologies utilisées  
- **Front-end** : 
-React
-HTML
-CSS
-react-hook-form
-react-toastify

- **Back-end** : 
-Express
-Node.js
-multer
-json-web-token
-cookie-parser
-argon2

- **Base de données** : MySQL  

## Installation  
Clonez ce dépôt :  
   git clone https://github.com/deknuydtbenjamin/greenshare.git

  cd GREENSHARE

Créer les variables d'environnement (.git) selon les .env.sample

Configuration de la base de données :

npm run db:migrate

Installation des dépendances :

Pour le frontend :

cd client npm install

Pour le backend :

cd ../server npm install

Lancement du projet :

npm run dev
